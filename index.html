polyfill 生成

String.prototype.at ( index )

  1. Let O be the this value.
  2. Perform ? RequireObjectCoercible(O).
  3. Let S be ? ToString(O).
  4. Let len be the length of S.
  5. Let relativeIndex be ? ToIntegerOrInfinity(index).
  6. If relativeIndex ≥ 0, then
    1. Let k be relativeIndex.
  7. Else,
    1. Let k be len + relativeIndex.
  8. If k < 0 or k ≥ len, return undefined.
  9. Return the substring of S from k to k + 1.

at(index) {
  var O = this;
  AO__RequireObjectCoercible(O);
  var S = AO__ToString(O);
  var len = S.length;
  var relativeIndex = AO__ToIntegerOrInfinity(index);
  if ((relativeIndex >= 0))
  {
    var k = relativeIndex;
  }
  else
  {
    var k = (len + relativeIndex);
  }
  if (((k < 0) || (k >= len)))
  {
    return undefined;
  }
  return IN__SubString(S, k, (k + 1));
}

ここからは型検査の話

Algorithm Step のパース

7.2.3 IsCallable ( argument )

The abstract operation IsCallable takes argument argument (an ECMAScript language value) and returns a Boolean. It determines if argument is a callable function with a [[Call]] internal method. It performs the following steps when called:

  1. If argument is not an Object, return false.
  2. If argument has a [[Call]] internal method, return true.
  3. Return false.
  • emu-clause（節）、h1（見出し）、emu-alg（手順）、emu-grammar（文法）を読み取る
  • 番号付きリストの入れ子がステップの木構造になる

es2026 のレンダリング結果 / sec-iscallable

パーサー

  1. Let len be ? LengthOfArrayLike(O).

パーサーの定義（Scala）


lazy val letStep: PL[LetStep] =
  ("let" ~> variable <~ "be") ~ endWithExpr ^^ {
    case x ~ (e, f) => f(LetStep(x, e))
  }

結果の AST


LetStep(
  Variable("len"),
  ReturnIfAbruptExpression(
    InvokeAbstractOperationExpression("LengthOfArrayLike",
      List(ReferenceExpression(Variable("O"))))))

「Let x be 式.」という言い回しをパーサーコンビネーターで定義している

ESMeta の出力を一部省略 / lang/util/Parser.scala#L111-L114

IR


def IsCallable(
  argument: ESValue,
): Boolean = {
  if (! (? argument: Record[Object])) {
    return false
  }
  if (exists argument.Call) {
    return true
  }
  return false
}
  • 見出しの型が IR の型注釈（ESValue、Boolean）になる
  • 仕様書の3ステップと1対1で対応している

型検査

宣言（見出し）IsCallable(argument: ESValue): Boolean
解析結果return false / true / false → Boolean ✓
  • CFGをたどって各変数がとりうる型を計算する
  • 宣言と解析結果が合わなければエラーにする
    • 戻り値の型の不一致
    • 存在しないフィールドへのアクセス
    • 引数の型の不一致
  • Record の型（PropertyDescriptor など）は手書きの型定義を使う
